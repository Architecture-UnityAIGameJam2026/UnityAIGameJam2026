# ON YOUR MARK · 영어 무전 대사 팩

근거리 검, 원거리 레일건, 아군 중재 AI의 음성 각 100개를 담았다. 총 300개, 15분 5초다. 영어 대사는 Jev의 선택 문구이자 영어 자막이다. 한국어 자막은 같은 ID의 `korean` 열에 있다.

| 역할 | 승인된 샘플 | 연기와 후처리 |
| --- | --- | --- |
| 원거리 · P2 | [레이저가 동료를 추적할 때](audio/ranged/ranged_laser_tracks_partner.wav) | 관측 결과를 차분하게 끊어 말한다. OF-04 헬멧 무전으로 높은 송신음과 얇은 히스를 넣었다. |
| 근거리 · P1 | [러셔를 유인할 때](audio/melee/melee_draw_rushers.wav) | 동료 곁에서 말하듯 낮고 빠르게 받는다. 같은 헬멧 계열에서 송신 버튼 잡음과 중저역을 강조했다. |
| 중재 AI | [두 플레이어가 접속했을 때](audio/control/control_first_wave_inbound.wav) | 양쪽이 가진 정보와 요청을 전달하고 합의를 확인한다. 일정한 박자에 보코더 배음, 전자 변조, 짧은 접속음을 섞었다. 파일과 참조 키는 `control`이다. |

## Jev가 대사를 선택할 때

현재 상태에서 유효한 행을 먼저 추린다. `trigger_en`의 사실을 게임에서 관측할 수 있어야 하고 발화자와 수신자가 일치해야 한다. HUD 교차 상태에서는 해당 수치를 읽을 수 있는 쪽을 확인한다. Jev에는 후보 ID, `english`, `trigger_en`, `speaker`, `recipient`를 보낸다. `tts_tags`는 ElevenLabs 입력 전용이다. 응답으로 현재 후보 중 ID 하나 또는 `none`을 받고, 해당 행의 `file`과 사용자 언어의 자막을 함께 재생한다.

예를 들어 P2가 실제 재장전을 시작했고 지상 적이 접근 중이면 `ranged_reload_cover`가 “Reloading. Cover me.”를 발화한다. 같은 시점에 재장전 완료 대사는 후보에서 제외한다. 어느 쪽도 현재 사건을 설명하지 못하면 `none`으로 무음을 유지한다.

| 구현 상태 | 근거리 | 원거리 | 중재 AI | 게임 쪽 적용 |
| --- | ---: | ---: | ---: | --- |
| `arena` | 73 | 72 | 34 | 현재 메인의 역할·무기·이동·적·웨이브에서 얻을 수 있는 상황. 시야, 동선, 상대의 이전 콜 등은 통합 시 별도로 관측한다. |
| `hud_demo` | 13 | 13 | 29 | SenseLink의 로컬 요청·동의·철회·반환 시연. 시연용 데이터 공급기가 발화 조건을 충족할 때 사용한다. |
| `design` | 14 | 15 | 37 | 원격 지원 효과, 실제 협동 단말기·소생, 네트워크 소유권 등 기획 조건. 대응 서버 판정을 구현했을 때 활성화한다. |

## 행동 연결

대사 84개가 행동에 연결된다. 216개는 상태 보고, 중재, 경고, 감사 등 안내 전용이다. `actions.json`의 `bindings`에서 행동별 대사와 실행 주체를 확인할 수 있다. `self`와 `partner`는 실행자를 기준으로 해석한다. 중재자가 말하는 경우에도 실제 실행자는 P1 또는 P2일 수 있다.

| 사건 | 대사 ID와 처리 |
| --- | --- |
| P2가 재장전하려 함 | 행동 의도를 제안하는 단계에서는 서버가 유효성·제어 권한을 검사하고 실제 시작 사건에 `ranged_reload_cover`의 `started` 발화를 맞춘다. 이미 시작된 사건에서 골랐으면 재생만 한다. |
| P2 재장전 완료 | `ranged_reload_full`을 완료 사건에서만 재생한다. 이미 채운 탄창에 재장전을 다시 요청하지 않는다. |
| P1이 HUD 반환을 수락 | `control_terminal_available`은 중재자가 양측에 수락 소식을 전한다. 연결된 행동은 `return_hud`, 실행자는 `melee`, 대상은 그 파트너다. 로컬 시연용이며 실제 네트워크판은 공동 단말기 조건을 별도로 확인한다. |
| P2가 지도 교환을 철회 | `ranged_cancel_map`은 대기 제안이 실제로 사라진 후 `cancelled` 사건에서 재생한다. 소유권은 기존 값을 유지한다. |
| 무관한 사건 또는 미리 듣기 | 예를 들어 코스튬 변경은 이 팩에 맞는 후보가 없어 `none`이다. 미리 듣기는 WAV와 자막만 재생한다. |

`accepted`는 요청 수락, `started`는 실제 동작 개시, `completed`와 `cancelled`는 서버나 해당 시연 상태의 결과다. `observed`는 관측된 상황에 대한 안내다. 게임이 선택 단계에서 행동을 제안하도록 연결할 경우, 서버가 같은 결정과 행동을 한 번만 수락하고 사람이 조종하는 캐릭터에는 안내만 전달한다. 중재 AI의 발언으로 두 사람의 동의를 대신할 수 없다.

## 제작 검수

- 감정 태그를 붙여 `eleven_v3`로 각 문장을 생성하고, 승인된 샘플과 동일한 역할별 처리로 WAV를 만들었다. 세 샘플은 각 역할 100개에 포함된다.
- 최종 WAV 300개를 ElevenLabs Scribe v2로 다시 전사해 영어 자막과 대조했다. 오인식된 문장은 다시 작성·합성해 검사했다. 최종 300개 모두 발화 단어가 일치했다. 구두점·대소문자·축약·숫자 표기와 같은 발음의 미국·영국식 철자를 정규화했다.
- 모든 파일이 고유한 PCM 음원이고, 카탈로그와 WAV 사이에 누락·중복이 없으며, 실제 길이가 기록값과 일치한다. 전체 최대 샘플 피크는 −1.78 dBFS였다. 파일별 시작 효과음과 마지막 감쇠 구간도 검사했다.
- 승인 청취는 역할별 대표 3개, 전수 검수는 재전사와 신호 측정으로 진행했다. 행동 ID·발화 시점·실행 주체·대상·무음 예시는 정적으로 대조했다. Unity 플레이 및 실시간 Jev 호출은 후속 연동 시 검증할 항목이다.
