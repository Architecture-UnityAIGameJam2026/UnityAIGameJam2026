# garam 모델 프리팹

Unity **6000.3.28f1 / HDRP 17.3.0**용 모델 64종입니다. `Prefabs`의 프리팹을 씬으로 드래그해 사용하세요. FBX, 재질, 텍스처와 Unity `.meta`를 함께 포함합니다.

| 폴더 | 개수 |
|---|---:|
| `01_asteroids` | 11 |
| `02_pickups` | 12 |
| `03_cover` | 8 |
| `04_wreckage` | 25 |
| `05_hazards` | 8 |

공통 산업용 로우폴리 색감과 재질을 유지하면서 근접 시 거친 곡면과 흐린 표면을 개선했습니다. 전체 **2,444,208 삼각형**이며, 대표 돌 `03_drift_rock_intact`는 **21,728 삼각형**입니다. Meshy 생성 52종과 기존 Blender 제작 소품 12종을 사용합니다.

## 표면 선명도 개선

- 낮은 방벽은 축소 전 원본 **187,796 삼각형**으로 복원했습니다. 나머지 63종은 원래 꼭짓점·모서리·UV 경계를 보존하면서 곡면을 보간하여 삼각형 수를 4배로 늘렸습니다.
- Meshy 52종 모두 원본 노멀맵을 복원했습니다. 일반 모델은 2K, 거대 소행성·거주 모듈·함선 선수는 4K입니다. 노멀 강도는 공통 0.7입니다.
- 색상 텍스처도 같은 해상도로 다시 구웠습니다. 별도 보정된 드론과 긴/작은 금속판의 색상, Blender 소품 12종의 재질 색상은 유지합니다.
- Unity에서 메시 압축을 끄고 노멀맵을 선형 Normal Map으로 가져옵니다. Trilinear 필터와 이방성 8을 사용합니다.
- 원본에 없던 구조를 재생성한 것은 아닙니다. 보관된 형상과 표면 정보를 복원하고 곡면의 밀도를 보강했습니다. 전체 팩의 삼각형·텍스처 메모리 사용량은 이전 버전보다 증가합니다.

## 크기와 배치

- 원점은 바닥 중앙, 루트 Scale은 `(1, 1, 1)`입니다. 1 Unity 단위는 1 m입니다.
- 원본에 표기된 규모를 유지하므로 대형 소행성·함선은 소품보다 훨씬 큽니다. 용도에 맞게 씬 인스턴스 크기를 조절하세요.
- 시각 모델 프리팹이며, 게임용 Collider·Rigidbody·게임플레이 컴포넌트는 배치 용도에 따라 추가합니다.

## 일부 영역만 발광

발광은 별도 재질이 지정된 표시등 면 또는 검은 바탕의 UV 마스크로 제한합니다. 외장 전체에 발광 색을 곱하지 않습니다.

- 의료 상자 닫힘/열림, 주입기: 공통 `OYM_HealthGreen_Emissive` 재질의 작은 표시등만 발광합니다. 일반 초록 도색은 별도 비발광 재질입니다.
- 지뢰: 상단의 두 작은 황색 램프만 발광합니다. 몸체와 경고 줄무늬는 제외합니다.
- 유틸리티 박스: 작은 황색 표시 버튼만 발광합니다. 케이블의 도색은 제외합니다.
- 케이지형·기둥형 신호등: 중앙 또는 상단 렌즈만 발광합니다.
- 기존 황색·청록 소품 표시등, 허스크 소행성·비콘의 작은 발광 영역, 드론 중앙 렌즈도 유지합니다.

초록 표시등 및 추가 황색 램프의 기본 **Emission Intensity는 2.5**입니다. HDRP 재질 Inspector에서 0으로 끄거나 5 등으로 밝기를 조절할 수 있습니다. 공통 초록 재질을 편집하면 3종에 함께 적용됩니다. 텍스처 방식 재질에서는 **Emissive Color Map을 유지**해야 발광 범위가 보존됩니다.

빛 번짐은 씬의 HDRP Volume에서 Bloom을 켜면 나타납니다. 표시등 자체의 발광과 Bloom 효과는 별도로 조절할 수 있습니다.

## 재생성과 검증

Unity 메뉴:

- `Tools > Garam > Rebuild 64 Asset Prefabs`: 포함된 입력으로 재질·프리팹을 다시 생성합니다. 수동으로 수정한 프리팹과 재질은 먼저 별도로 보관하세요.
- `Tools > Garam > Validate 64 Asset Prefabs`: 모델 수, 실제 삼각형 수, 크기, 원점, HDRP 재질, 참조, 부분 발광 범위를 검사합니다.

입력 정보는 `Editor/asset-pack.json`, 전후 삼각형 수와 텍스처 해상도는 `Editor/fidelity-report.json`, Unity에서 실행한 검사 결과는 `Editor/validation-report.json`에 있습니다. 검증은 64종의 메시·크기·원점·참조, 노멀맵 52종과 부분 발광 15종(초록 표시등 3종 포함)을 검사합니다. 모델의 거칠기·금속성 텍스처는 HDRP Mask Map 채널 규칙에 맞게 변환했습니다. 원본 UV로 복구된 낮은 방벽은 공통 금속성 0.2, 거칠기 0.64를 사용합니다.
